# membership 라인의 키는 `tradingitemid` 단독, 해석 실패 시 `isin` 폴백

ADR-0005 는 membership 을 `(isin, tradingitemid)` **쌍**으로 키잉했고, 편입 시점의 tid 로 해석되지 않은 ISIN 은 **버렸다**(경고만). 둘 다 실측에서 문제를 냈다.

## 쌍 키가 낳은 문제 — 조용한 15개월 손실

SPY+QQQ 전 이력에서 tid `26254887`(VMED, Virgin Media)이 **ISIN 둘**로 편입돼 있다:

| membership 라인 | 편입 | 가격 행 |
|---|---|---|
| `US62940M1045` / 26254887 | 15개월 (2004-12~2006-02) | **0행** |
| `US92769L1017` / 26254887 | 73개월 (2006-03~2013-05) | 2,686행 (2002-09~2013-06) |

ISIN 재발급이다. 홀딩스는 그때그때의 ISIN 을 적지만 가격 행에는 **현재 기준 ISIN 하나만 각인**돼 있어(ADR-0004) 패널 컬럼은 `US92769L1017` 하나뿐이다. 그래서 패널 컬럼 라벨로 membership 을 정렬하면 **2004-12~2006-02 편입 15개월이 조용히 사라진다** — 그 15개월 가격은 패널에 멀쩡히 있는데도.

## 버리기가 낳은 문제 — 119개월이 통째로 없어짐

`US85220G1094` 는 1999-12~2009-10 **119개월 연속** 편입인데 어느 달에도 tid 로 해석되지 않는다(해석된 달 0개). 지금까지는 경고 한 줄만 남기고 membership 에서 사라졌다.

## Decision

- **라인 키 = `tradingitemid` 단독.** 같은 tid 의 여러 ISIN 은 한 컬럼으로 접는다(OR). 시기가 겹치지 않으므로 OR 은 정확하다 — VMED 실측 15+73 = **88개월**.
- **tid 로 해석되지 않은 ISIN 은 `isin` 을 키로 남긴다.** 그 라인의 `tradingitemid` 레벨은 `<NA>` 다.
- **isin 라벨은 마지막 편입 시점의 ISIN.** 가격 행에 각인된 ISIN 이 그것이다 — 실측 VMED 는 `US92769L1017` 로 패널과 일치한다. (**정정(ADR-0009)**: 그 일치는 VMED 한 건에서만 성립했다. 실측 20건은 홀딩스의 마지막 ISIN 과 가격 행 각인 ISIN 이 어긋난다. 라벨은 **그 tid 의 최신 ISIN** 으로 통일하고 패널 컬럼도 같은 map 으로 덮는다.)
- **tid 레벨 dtype 은 nullable `Int64`.** `<NA>` 때문에 float64 로 내려가면 `26254887.0` 이 되어 패널의 int64 와 안 맞는다.

ADR-0005 가 "tid 단독 키잉"을 기각한 사유는 *"ISIN 결을 잃어 미커버 목록이 안 나온다"* 였다. 그 기각은 **키와 레벨을 같은 것으로 본** 데서 나왔다. ADR-0007 이후 membership 컬럼은 `(ticker, name, isin, tradingitemid)` 레벨을 다 갖는다 — 키를 tid 로 좁혀도 `isin` 레벨이 남으므로 `uncovered` 파생은 그대로다.

## 결과 (SPY+QQQ, start=1999-12-31)

| | 전 | 후 |
|---|---|---|
| membership 컬럼 | 1,227 | **1,227** (tid 키 1,226 + isin 키 1) |
| VMED | 2컬럼 (15 / 73개월) | **1컬럼 88개월**, 라벨 `US92769L1017` |
| `US85220G1094` | 없음 (버려짐) | **1컬럼 119개월**, tid `<NA>` |
| tid 레벨 dtype | int64 | **Int64** |
| 패널(1,224 tid) 과 교집합 | 1,221 | 1,221 (mem-only 5, panel-only 3 — ADR-0006 참조) |

총 컬럼 수는 우연히 같지만 구성이 다르다: 접혀서 −1, 살아나서 +1.

## Consequences

- **`<NA>` 비교는 NA 안전하게 해야 한다.** `c[3] == 26254887` 은 그 라인에서 `TypeError: boolean value of NA is ambiguous` 다. `pd.notna(v) and v == x`, 벡터로는 `.to_series().eq(x).fillna(False)` 를 써라.
- **접기가 정보를 하나 지운다** — "2004~2006 엔 옛 ISIN 으로 편입돼 있었다". 조용히 지우지 않도록 접힌 tid 와 버려진 ISIN 목록을 경고로 발행한다.
- **부분 해석 ISIN**(어떤 달은 tid, 어떤 달은 미해석)이 생기면 한 종목이 두 컬럼으로 갈린다. 현재 유니버스엔 0건이지만 생기면 경고한다.
- **캐시 무효화**: membership 모양이 바뀌므로 `UNIVERSE_SHAPE_VER` 를 1 → 2 로 올렸다.
